# StarTech Website Test - Selenium Automation Practice Project

A web automation project for practice built with **Selenium WebDriver** and **JavaScript (Node.js)** for automating user interactions on the Star Tech website https://www.startech.com.bd .

## Features Tested
- Homepage load
- Offer Page
- Product search automation
- Login automation
- Product navigation
- Search product and verify
- Add to Cart automation
- Checkout
- purchase a product
- Category
## Test Scenarios

- Homepage loading
- Offer Page Verify
- Product Search
- Product Details
- Add to Cart
- Purchase a product
- Login
  
## Tech Stack

- JavaScript (Node.js)
- Selenium WebDriver
- ChromeDriver
- npm

## Installation

Clone the repository:

```bash
git clone https://github.com/ankandas101/startech-selenium-automation.git
```

Move into the project directory:

```bash
cd startech-selenium-automation
```

Install dependencies:

```bash
npm install
```

## Run Tests

Run a specific test:

```bash
node test.js
```

Or run another test:

```bash
node tests/searchProduct.test.js
```

## Dependencies

```bash
npm install selenium-webdriver
```
